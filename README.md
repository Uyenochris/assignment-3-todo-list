Homework 3 To-Do List

This is my Homework 3 app I made it using React Native and Expo You can add and delete tasks.

How to Run

1. Download Node.js and Expo Go.
2. Open the project in VS Code.
3. Type npm install in the terminal.
4. Type npx expo start.
5. Scan the QR code with your phone.

How to Use

Type a task and press Add. Press X to delete it.
